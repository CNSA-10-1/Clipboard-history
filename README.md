# 剪贴板历史

Windows 10 上的剪贴板历史工具。后台常驻，自动记住你复制过的**文字、图片和文件**，需要时打开翻查、搜索，再粘贴一次。

C# / WPF / .NET 9，**零第三方依赖**——不装任何 NuGet 包。

---

## 为什么做这个

Windows 自带的 `Win+V` 有四个不够用的地方：存不了几条、不能搜索、不能置顶、留不了几天。这个工具把这四件事都补上了。

## 它能做什么

**记录**

- 后台自动记录复制的文字、图片、文件/文件夹，不用手动操作
- 复制**图片文件**（`.jpg` / `.png` 等）时自动生成缩略图，卡片里直接看到内容（含相机照片的 EXIF 方向纠正）
- **文件**和**文件夹**分开记，筛选时能找到
- 不保留富文本格式，一律存纯文字
- 内容相同的重复复制**合并成一条**，只刷新时间

**查看与查找**

- 卡片列表，最新在最上面；置顶的归到顶部「已置顶」分组
- 关键词搜索，边打字边过滤
- 类型筛选：全部 / 文字 / 图片 / 文件 / 文件夹
- 长内容底部渐隐，点「展开」看全部；展开后在卡片内部滚动

**操作**

- **点卡片 = 复制**（所有类型都一样），窗口随即自动隐藏，你回原窗口 `Ctrl+V`
- 卡片右上角圆形按钮：`📌` 置顶、`⊗` 删除（删除不弹确认框）
- 右键菜单：复制 / 置顶 / 删除
- 键盘操作：`Esc` 隐藏、`↑↓` 选卡片、`Enter` 复制、`Delete` 删除、`Ctrl+F` 搜搜索框
- 文字里的网址**蓝色下划线**，点它开浏览器；点卡片其它地方仍然是复制
- 文件卡片里能看每个条目的**大小**和**完整路径**，点路径在资源管理器里定位

**常驻与自动清理**

- 只在托盘放一个图标，不占全局快捷键
- 按 `×` 关窗口**不退出程序**，只是隐藏，继续在后台记录
- 开机自动启动（可关）
- 单实例：重复启动只会把已有窗口叫出来
- 保留天数自己填（1–365），**置顶的内容永不过期**
- 容量上限自己填，超出后从最旧的、没被置顶的开始删
- 启动时自检数据文件夹，清理孤儿图片和残留临时文件

**外观**

- 浅蓝主色，Windows 10 设计语言
- 主题：浅色 / 深色 / 跟随系统

## 运行要求

- 64 位 Windows 10 / 11
- **.NET 9 桌面运行时**（Desktop Runtime）

> 仓库里**不含**打包好的 exe，需要自己编译（见下）。
> 如果目标电脑不想装 .NET，可以用 `build-standalone.bat` 打一个自包含版本，
> 代价是体积大（150 MB 上下）。

## 编译与运行

```bat
dotnet build
dotnet run
```

或双击 `build.bat` 一键打包。

| 脚本 | 产物 | 说明 |
|---|---|---|
| `build.bat` | `bin\Release\...\publish\剪贴板历史.exe` | 约 390 KB，需要目标电脑装了 .NET 9 |
| `build-standalone.bat` | `dist\剪贴板历史.exe` | 自包含，拷到任何 64 位 Windows 直接跑，体积大 |

> 需要 .NET 9 SDK。用 `dotnet --list-sdks` 确认。

## 数据存在哪

```
%AppData%\ClipboardHistory\
├─ index.json      # 所有条目的元数据
├─ settings.json   # 你的设置
├─ images\         # 图片原图与缩略图
└─ error.log       # 出问题时才有内容
```

**全部本地存储，不联网、不上传。** 设置窗口里有「打开数据文件夹」按钮。

想迁移到别的电脑：把整个文件夹拷过去即可（注意 `index.json` 里的文件卡片指向的是原电脑的路径，拷过去后会显示为「失效」）。

## 项目结构

```
├─ App.xaml(.cs)            启动、单实例互斥、主题初始化
├─ MainWindow.xaml(.cs)     历史列表主窗口
├─ SettingsWindow.xaml(.cs) 设置窗口
├─ Models/                  数据模型
├─ Services/                剪贴板监听、存储、托盘、清理、开机自启…
├─ Converters/              数据绑定用的转换器
├─ Ui/                      窗口外观、图标、自定义控件
├─ Themes/                  浅色 / 深色配色与通用样式
├─ Interop/                 Win32 API 声明
├─ Assets/app.ico           托盘与 exe 图标
└─ build.bat                一键打包
```
