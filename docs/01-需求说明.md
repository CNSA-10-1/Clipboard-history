# 需求说明

> 用大白话写"要什么"，不涉及技术实现。
> **需求有变化，先改这份文件**，再去改代码。

## 一句话

一个常驻在 Windows 10 后台的剪贴板历史工具：自动记住复制过的文字、图片和文件，需要时打开翻查、搜索、再粘贴一次。

## 为什么要做

Windows 10 自带的 `Win+V` 剪贴板历史有四个不够用的地方：

- 只能存很少几条
- 不能搜索
- 不能置顶
- 存不了多久

## 功能需求

### 1. 记录

- 后台自动记录复制的**文字**、**图片**、**文件/文件夹**，不需要手动操作
- **文件**和**文件夹**要能区分开（类型筛选用得到）
- **不保留**复制内容的格式（加粗、颜色、超链接等），一律存纯文字
- **复制图片文件（.jpg / .png 等）也算"图片"**：从资源管理器复制一张照片，它就是一张图片，
  不该被当成普通文件。卡片上要给**缩略图预览**，不能只显示一个文件图标

> **"图片"和"文件"的界线**：图片文件只在「图片」里出现，不出现在「文件」里——
> 否则「文件」筛选会被一大堆照片淹没，而「图片」里反倒一张都没有。
> "2 张照片 + 1 个 pdf"这种混合复制会**同时**出现在「图片」和「文件」下，不会被藏起来。

### 2. 保留与清理

- 保留天数**用户自己填**，默认 3 天；提供 1 / 3 / 5 / 7 / 30 天的快捷按钮
- **置顶的内容永不过期**
- 总容量**用户自己填**，默认 500MB；超出后先删最旧的、且没被置顶的
- 复制重复内容时**只留一条**，把时间更新成最新，不重复堆卡片

### 3. 查看

- 打开后是**卡片列表**，最新的在最上面
- 置顶的卡片归到顶部「已置顶」分组
- 卡片上显示内容预览 + 相对时间（"3 分钟前"、"昨天"）
- 底部状态栏显示：共多少条、占用多少空间、当前保留几天

### 4. 搜索

- 关键词搜索框，**边打字边过滤**，不需要按回车
- **类型筛选**：全部 / 文字 / 图片 / 文件 / 文件夹，同一时刻选一个，默认「全部」
- 筛选和关键词**同时生效**（"且"的关系）
- **归类规则**（见上面「记录」一节的说明）：图片文件算「图片」不算「文件」；
  含多个条目的混合卡片在对应的几个筛选下**都会出现**，不会被二选一

### 5. 卡片操作

- 卡片**右上角有圆形按钮**：`📌` 置顶、`⊗` 删除
- 删除**立即生效，不弹确认框**
- **点卡片本身 = 复制**。这条对**所有类型**的卡片都成立：内容复制回剪贴板，窗口自动隐藏，用户自己按 `Ctrl+V`
- 右键卡片有菜单：复制 / 置顶（取消置顶）/ 删除

### 5.1 内容装不下时的渐隐与展开

卡片装不下时，**底部做一层渐变淡出**，暗示"下面还有内容"，并给一个**展开按钮**：

- 文字卡片：超过 3 行
- 文件卡片：复制的条目多于一个
- 图片卡片：多张图片

点展开能看到全部内容，再点收起。内容本来就装得下时，**不显示渐隐、也不显示展开按钮**。

**展开后在卡片内部滚动，而且要看得到滚动条。** 光能滚、看不见滚动条的话，用户不知道还能往下翻。
滚动条要细一点，不要系统默认那种带上下箭头的粗滚动条。
收起状态**不显示滚动条**（否则一条空槽挂在文字旁边，看着像出错）。

### 5.2 网址要能点开

文字内容是网址时，显示为**蓝色 + 下划线**。

- **点网址本身** → 用默认浏览器打开
- **点卡片其它地方** → 还是复制

不能因为卡片里有网址，就变成"点哪儿都跳浏览器"。

### 5.3 文件 / 文件夹卡片要能看详情

文件卡片和文件夹卡片上有一个**下拉按钮**，展开后列出每个条目的：

- **大小**
- **完整路径**，而且路径**可以点击**——点了用资源管理器打开所在位置

下拉按钮只负责展开详情，**不影响"点卡片 = 复制"**。

### 6. 怎么打开

- **只在右下角托盘放一个图标**，点它打开
- **不占用**全局快捷键（避免和其他软件冲突）

### 7. 运行方式

- **开机自动启动**（可以随时关掉）
- 按窗口的 `×` **不退出程序**，只是最小化到托盘，继续在后台记录
- 只有从托盘图标右键菜单里才能真的退出

### 8. 设置

- 保留天数（自己填）
- 最大存储容量（自己填）
- 开机自动启动（开关）
- 主题：浅色 / 深色 / 跟随系统
- 按钮：打开数据文件夹
- 按钮：清空全部历史（**要二次确认**）

## 界面要求

- 简洁、直观，不要花里胡哨
- 主色调**淡蓝色**
- 符合 **Windows 10** 的设计风格
- 能跟随系统的深色模式

## 明确不要的

| 不要 | 原因 |
|---|---|
| 富文本格式保留 | 存纯文字更清爽，也更好搜索 |
| 全局快捷键 | 避免和其他软件抢键 |
| 自动粘贴 | 只复制到剪贴板，用户自己按 `Ctrl+V`，兼容性最稳 |
| 云端同步 | 全部本地存储，不涉及网络 |
